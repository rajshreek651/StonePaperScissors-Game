# StonePaperScissors-Game
When our childhood game of Stone-Paper-Scissors transforms into a web app through coding, it’s like giving nostalgia a modern twist. What was once decided with quick hand gestures is now recreated with sleek buttons and smart logic. The fun remains the same—but now it lives in browsers, not just in playgrounds. It's a beautiful reminder that even the simplest games can be reborn in the digital world. This is one of my projects which created my base in developing web projects and gave a deep understanding of DOM manipulation and JavaScript Event Handling.
